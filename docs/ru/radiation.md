# Радиация

`RadiationManager` хранит числовое значение радиации сущности отдельно от эффектов Minecraft. Данные записываются в NBT живых сущностей; значение игрока переносится при возрождении. Все изменения выполняются через `addRadiation`, `removeRadiation` и `clearRadiation`; текущее значение можно получить через `getRadiation`.

## Источники и модификаторы

У предмета может быть компонент `ModComponents.RADIOACTIVITY` с числовой дозой. Доза каждого радиоактивного предмета в руке прибавляется через заданный интервал. Компонент добавляется прямо к настройкам любого предмета или `BlockItem`, например:

```java
new Item(new Item.Settings()
        .maxCount(16)
        .component(ModComponents.RADIOACTIVITY, 20.0))
```

Для нового источника, не являющегося предметом в руке, используй `RadiationManager.registerExposureSource(...)`. `RadiationModifier` позволяет экипировке менять множитель накопления, а временным эффектам — добавлять выведение радиации. Лекарства и предметы для лечения пока не реализованы.

## Настройка

После первого запуска создаётся `config/spacestation-radiation.properties` в каталоге конфигурации сервера. Изменения применяются после перезапуска.

- `itemExposureIntervalSeconds`: интервал в секундах между дозами радиоактивных предметов в руках. Значение компонента определяет размер дозы; устаревший ключ `uraniumIntervalSeconds` поддерживается как fallback.
- `naturalDecayPerSecond`: естественное выведение за секунду.
- `effectRefreshIntervalSeconds`: период обновления симптомов.
- `level1`–`level5`: порог, флаги тошноты/слабости/замедления, усилители и периодический урон с интервалом в секундах.

Пороговые значения должны строго возрастать. Уровень симптомов пересчитывается при изменении радиации, а действующие эффекты обновляются периодически, не каждый тик.

## Добавление механики

Для нового источника вызови `registerExposureSource` при инициализации мода с предикатом обнаружения игрока, дозой и интервалом в тиках. Для защитной экипировки или временного ускорения выведения зарегистрируй реализацию `RadiationModifier`. Изменять NBT радиации напрямую нельзя: это обходит единый менеджер.
