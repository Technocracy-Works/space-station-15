# Документация разработчика SpaceStation 15

Эта документация объясняет текущую структуру проекта и показывает, как безопасно расширять код. Проект создан на: Minecraft 1.21.1, Java 21, Fabric API, Yarn mappings.

## С чего начать

- [Настройка](setup.md): среда разработки, Gradle и требования.
- [Архитектура](architecture.md): энтрипоинты, сеты источников, порядок инициализации и карта модулей.
- [Регистры](registries.md): регистрация предметов, блоков, звуков, экранов, компонентов и блок энтити.
- [Предметы](items.md): категории предметов, helper-классы, кастомное поведение и добавление новых предметов.
- [Блоки](blocks.md): блоки, растения, сборка/разборка, блок энтити, модели, лут и добавление новых блоков.
- [Химия](chemistry.md): Chem Master, химические контейнеры, реакции, рецепты дробления и форматы данных.
- [Сеть](networking.md): custom payload'ы, поток клиент/сервер и текущие места использования.
- [Сохранение](saving.md): data components предметов, NBT блок энтити и data-driven ресурсы.
- [Радиация](radiation.md): хранение радиации игрока, источники, модификаторы и конфигурация.
- [События и таймеры](events.md): Fabric events, таймеры, HUD прогресса и изменение лут тейблов.
- [Ресурсы](resources.md): assets, datapack-данные, lang-файлы, рецепты, worldgen JSON и нейминг.
- [Генерация мира](worldgen.md): регистрация руд и структура JSON.
- [Стиль кода](coding_style.md): правила кода и ожидания к изменениям.
